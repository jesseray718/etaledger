# Contributing

Thanks for helping. This repository follows a small set of rules that keep the
lattice healthy.

## Workflow

1. Fork or branch from the default branch.
2. Keep pull requests focused: one logical change per PR.
3. Write a description of at least a short paragraph: what changed and why.
4. Make sure CI (the *antifragility lair* workflow) passes.

## Merge policy

- Squash-merge only; head branches are deleted on merge.
- Pull requests are merged once CI is green.
- Direct pushes to the default branch are discouraged.

## Style

- Match the surrounding code and formatting.
- Do not commit build artifacts, caches, logs, pid files, or editor backups.
- Keep documentation honest: no placeholder links.

## Reporting problems

Bugs and feature requests go through GitHub issues. Security issues follow
[SECURITY.md](SECURITY.md).
