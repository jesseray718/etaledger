# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Use GitHub's private vulnerability reporting: open this repository's
**Security** tab and choose **Report a vulnerability**, or contact the owner
through their GitHub profile.

## What to include

- A short description of the issue and its impact.
- Steps or a proof of concept to reproduce it.
- Any known workarounds.

## Response targets

- Acknowledgement: within 7 days.
- Triage and severity assessment: within 14 days.
- Fix or mitigation plan: within 30 days for high-severity issues.

## Scope

All code and workflows in this repository. The project maintains a canonical
*antifragility lair* CI workflow; security-relevant CI failures are treated as
bugs, not noise.
